### 3. [Credit Risk Engine](https://github.com/dona-eric/Hack2Hiere_TechTech_DataScience_20) — Scoring crédit explicable

- 🎯 **Résultat** : **1er prix du hackathon Hack2Hire TechTech Data Science** ; +15 % de précision vs baseline.
- 🛠️ **Tech** : `Scikit-Learn`, `SHAP`, `FastAPI`, `MLflow`.
- 🔗 [Démo](https://risk-score.streamlit.app)

### 4. [CoachAI](https://github.com/dona-eric/CoachAI) — Générateur IA de programmes sportifs
> Application LLM de coaching personnalisé (entraînement, récupération, nutrition).

- 🎯 **Résultat** : application Streamlit déployée ; gain de temps estimé à ~20 %.
- 🛠️ **Tech** : `LangChain`, `Groq`, `Llama 3`, `RAG`, `Streamlit`.

### 5. [AQI Cotonou](https://github.com/dona-eric/AirQuality) — Qualité de l'air en temps réel
